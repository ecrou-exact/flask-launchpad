Diff Viewer

Side-by-side or unified diff — intraline highlights, synchronized scroll, hunk navigation, custom colors.

diff-viewer.js
Usage 
import DiffViewer from '/static/js/components/diff-viewer.js'

<diff-viewer
    left-label="Original"
    right-label="Modified"
    :initial-left="old_text"
    :initial-right="new_text">
</diff-viewer>

Code Viewer

Syntax highlighting via highlight.js — JSON fold tree, integrated search, line numbers, copy.

code-viewer.js
Usage 
import CodeViewer from '/static/js/components/code-viewer.js'

<!-- JSON with fold tree (auto-detected) -->
<code-viewer :code="json_str" title="config.json"></code-viewer>

<!-- Explicit language -->
<code-viewer :code="source" language="python" title="app.py"></code-viewer>

Smart Editor

Rich form field — plain text, Markdown with live preview, and code with syntax highlighting. Auto-close brackets, smart indent, v-model and form-name compatible.

smart-editor.js
Current value [[ editor_values[active_editor_demo].slice(0, 200) || '(empty)' ]]
Usage 
import SmartEditor from '/static/js/components/smart-editor.js'

<!-- v-model, markdown mode -->
<smart-editor v-model="body" mode="markdown"></smart-editor>

<!-- Plain form field (no Vue) — submits with the form -->
<smart-editor name="content" mode="code" language="python"></smart-editor>

<!-- Props -->
mode        'text' | 'markdown' | 'code'     (default: 'text')
language    'javascript' | 'python' | ...    (code mode)
name        HTML name → hidden input for form submit
min-height  CSS string   (default: '220px')
max-height  CSS string   (default: '600px')
