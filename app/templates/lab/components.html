Diff Viewer

Side-by-side or unified diff between two texts (JSON, plain text, config files). Intraline character highlighting, synchronized scroll, hunk navigation.

diff-viewer.js
Usage 
import DiffViewer from '/static/js/components/diff-viewer.js'

// In components: { DiffViewer }
// In template:
<diff-viewer
    left-label="Original"
    right-label="Modified"
    :initial-left="old_text"
    :initial-right="new_text">
</diff-viewer>

// Or empty (user pastes / imports files):
<diff-viewer></diff-viewer>
