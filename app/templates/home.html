What's included

Authentication

Login, registration, session management and role-based access control. Admin, Editor, Read-Only out of the box.

REST API

Flask-RESTX with Swagger UI. API key authentication, namespaces, and input validation ready.

Feature Flags

Enable or disable features at runtime without redeployment. Per-feature routing guard and nav link control.

Vue 3 Components

Composition API, ES modules, DataTable, Pagination, LoadingBar and Toast — no build step required.

Alembic Migrations

SQLAlchemy + Alembic with a one-command workflow via ./launch.sh.

Test Suite

Pytest with role-based fixtures. HTML, API, and security tests included. Run with ./launch.sh --test.
